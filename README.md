# F25-AI-Lab

## Overview

This repository contains the solutions and documentation for the Artificial Intelligence (AI) Laboratory.

The repository is organized according to the lab structure provided by the instructor. Each lab folder contains:

- Python source code files (`.py`) implementing the required tasks.
- Documentation files (`.docx`) explaining the approach, logic, and implementation details used to solve the tasks.

## Repository Structure

```text

│
├── Lab-01/
│   ├── task_no_solution.py

├── Lab-02/

├── Lab-03/

```

## Purpose

The purpose of this repository is to:

- Maintain a structured record of AI lab assignments.
- Submit laboratory tasks through GitHub as instructed by the course instructor.
- Document both the implementation and the reasoning behind each solution.
- Practice version control and project organization using Git and GitHub.

## Contents of Each Lab Folder

### Python Code (`.py`)
Contains the implementation of the assigned lab tasks and algorithms.

### Documentation (`.docx`)
Contains:
- Problem description
- Solution methodology
- Explanation of the code
- Observations and results
- Any assumptions made during implementation

## Technologies Used

- Python
- Git
- GitHub
- Microsoft Word (.docx)

## Submission Requirements

For each lab, the following files are included:

1. **Python Code File (.py)**
2. **Word Document (.docx)**

These files are organized inside their respective lab folders as required by the course instructions.
